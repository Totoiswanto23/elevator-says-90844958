The funniest one line a talking elevator could say: "Going up. Going down. I have watched you rehearse your breakup speech for three floors now. Good luck." The elevator announces itself in its own voice — going up, going down — then the turn: it has ridden along with you floor after floor while you practised what to say, and it wishes you luck. The joke lands on the first read, needs no setup, and could come from no other machine.

## Run it

```sh
node main.ts
```

It writes the single line (102 characters, no trailing newline) to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set.
